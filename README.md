# 📝 Fullstack Blog Platform

A production-ready fullstack blog application built with React, Node.js, and MongoDB.

This project was designed to simulate a real-world web application with authentication, RESTful APIs, containerized environments, and CI/CD automation.

---

## 🚀 Features

- User authentication and authorization using JWT
- Create, edit, and delete blog posts
- Protected routes for authenticated users
- RESTful API architecture
- Persistent data storage with MongoDB
- Containerized development and production environments
- Automated CI/CD pipeline with GitHub Actions

---

## 🏗️ Architecture

The application follows a modular fullstack architecture:

- **Frontend:** React (client-side rendering)
- **Backend:** Node.js + Express (REST API)
- **Database:** MongoDB
- **Authentication:** JWT-based authentication
- **DevOps:** Docker & GitHub Actions

The backend is structured using separation of concerns principles, isolating routes, controllers, and business logic.

---

## 🐳 Containerization

The application is fully containerized using Docker.

- Development and production configurations
- Isolated environments
- Reproducible setup across systems
